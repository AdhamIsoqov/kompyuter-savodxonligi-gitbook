# 02-Mavzu: Kompyuter Bilan Tanishuv va Arxitektura

{% hint style="info" %}
**Dars maqsadi:** Kompyuterning apparat ta'minoti (Hardware) asosiy komponentlari, ularning vazifalari va tizim bloki ichidagi o'zaro bog'liqlik mexanizmlarini o'rganish.
{% endhint %}

### 🎯 Kutilayotgan Ko'nikmalar
* **Bilishingiz kerak:** Protsessor (CPU), Ona plata (Motherboard), Tezkor xotira (RAM), Doimiy xotira (SSD/HDD) va Quvvat bloki (PSU) vazifasi.
* **Bajara olishingiz kerak:** Kompyuter parametrlarini Windows orqali aniqlash (`dxdiag`, `msinfo32`, Task Manager).
