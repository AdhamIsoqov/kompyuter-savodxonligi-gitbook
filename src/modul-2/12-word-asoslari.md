# 12-Mavzu: Microsoft Word Asoslari: Matn Terish va Formatlash

{% hint style="info" %}
**Dars maqsadi:** Microsoft Word dasturining interfeysi bilan tanishish, standart rasmiy hujjat talablari bo'yicha matn terish madaniyati, shriftlar (Font), abzaslarni tekislash (Alignment: Justify), qatorlar oralig'i (Line Spacing) va xatboshini (First Line Indent) professional sozlash ko'nikmalarini egallash.
{% endhint %}

### 🎯 Kutilayotgan Kompetensiyalar
* **Bilishingiz kerak:**
  * Rasmiy hujjatlarning davlat standarti bo'yicha parametrlari (Times New Roman, 14 pt, 1.5 yoki 1.15 interval, Justify).
  * `Enter` (yangi abzas) va `Shift + Enter` (abzasni buzmasdan yangi satr) o'rtasidagi farq.
  * Xatboshi hosil qilishda nima uchun probel (Spacebar) bosish qat'iyan man etilishi.
* **Bajara olishingiz kerak:**
  * Shrift parametrlarini tezkor boshqarish: Bold (`Ctrl + B`), Italic (`Ctrl + I`), Underline (`Ctrl + U`).
  * Abzaslarni to'rt tomondan to'g'ri tekislash: Chapga (`Ctrl + L`), O'rtaga (`Ctrl + E`), O'ngga (`Ctrl + R`), Ikki tomonga (`Ctrl + J`).
  * Chizg'ich (Ruler) orqali birinchi satr xatboshisini (First Line Indent: 1.25 sm) o'rnatish.

## 2. 📖 Chuqurlashtirilgan Nazariy Ma'ruza

### 2.1. Rasmiy Hujjat Formatlash Standartlari

O'zbekiston Respublikasi idoraviy ish yuritish qoidalariga ko'ra barcha rasmiy arizalar, bildirishnomalar va hisobotlar quyidagi qat'iy standartlarga javob berishi shart:

| Parametr | Standart Qiymat | O'rnatish Usuli |
| :--- | :--- | :--- |
| **Shrift turi (Font)** | `Times New Roman` | Bosh sahifa (Home) -> Shrift tanlash |
| **Asosiy matn o'lchami** | `14 pt` (Jadvallarda 10–12 pt) | Font Size darchasidan |
| **Tekislash (Alignment)** | `Justify` (Ikki tomonga tekis) | `Ctrl + J` tugmasi |
| **Qatorlar oralig'i** | `1.15` yoki `1.5` qator | Line and Paragraph Spacing |
| **Xatboshi (Abzas boshi)** | `1.25 sm` | Gorizontal chizg'ichdagi yuqori uchburchak |
| **Varaq hoshiyalari (Margins)** | Chap: 3 sm, O'ng: 1.5 sm, Yuqori/Past: 2 sm | Layout -> Margins |

```
[Chizg'ichdagi Abzas Belgilari (Ruler)]
   ▼  <--- Yuqori uchburchak: Birinchi satr xatboshisi (First Line Indent - 1.25 sm)
   ▲  <--- Pastki uchburchak: Qolgan satrlar siljishi (Hanging Indent)
  [■] <--- To'rtburchak: Butun abzasni surish (Left Indent)
```

{% hint style="success" %}
**Pro-Tip (Matn terishning "Oltin Qoidalari"):**
1. So'zlar orasida hech qachon ketma-ket 2 ta probel qo'yilmaydi!
2. Tinish belgilari (nuqta, vergul, ikki nuqta, qavs) o'zidan oldingi so'zga yopishtirib yoziladi, belgidan so'ng esa majburiy bitta probel qo'yiladi (Masalan: `Toshkent, O'zbekiston`).
3. Qavs va qo'shtirnoq ichidagi matnga probel qo'shilmaydi (Masalan: `(Kompyuter)` to'g'ri, `( Kompyuter )` xato).
{% endhint %}

### 2.2. Tezkor Tahrirlash va Shrift Kombinatsiyalari

| Tugmalar | Funksiyasi | Nima uchun muhim? |
| :--- | :--- | :--- |
| `Ctrl + A` | Hujjatdagi barcha matnni bitta buyruq bilan belgilash | Shriftni bir vaqtda 14 pt qilish uchun |
| `Ctrl + B` | Matnni qalin (Bold) qilish | Muhim so'zlar va sarlavhalarni ajratish |
| `Ctrl + I` | Matnni yotiq / kursiv (Italic) qilish | Izohlar va iqtiboslar uchun |
| `Ctrl + U` | Matn tagiga chizish (Underline) | Havolalar va maxsus bandlar uchun |
| `Ctrl + E` | Matnni markazga tekislash | Hujjat sarlavhalari uchun |
| `Ctrl + J` | Matnni ikki chetga tekislash (Justify) | Rasmiy va tartibli ko'rinish berish |
| `Shift + F3` | Belgilangan so'zning registrini almashtirish | KICHIK -> Bosh Harflar -> HAMMASI KATTA |

### Bajarish Bosqichlari:

1. **1-Qadam:** Microsoft Word dasturida bo'sh hujjat oching (`Ctrl + N`).
2. **2-Qadam (Boshlang'ich parametrlar):** `Ctrl + A` bosing, shriftni **Times New Roman**, o'lchamini **14**, oraliqni **1.15** qilib belgilang.
3. **3-Qadam (Ariza "shapkasi"):** O'ngga tekislash (`Ctrl + R`) orqali arizaning kimga yo'llanayotgan qismini yozing:
   * *O'quv markazi direktori A. Karimova ga*
   * *Tinglovchi Sh. Nazarov dan*
4. **4-Qadam (Sarlavha):** Ikki marta Enter bosing, markazga tekislash (`Ctrl + E`) va qalin shrift (`Ctrl + B`) orqali **ARIZA** deb yozing.
5. **5-Qadam (Asosiy matn):** Enter bosing, tekislashni `Ctrl + J` (Justify) ga o'tkazing. Gorizontal chizg'ichdagi yuqori uchburchakni `1.25 sm` ga surib, quyidagi matnni kiritishni boshlang:
   * *Menga kompyuter savodxonligi kursi bo'yicha amaliy laboratoriya mashg'ulotlarini bajarishim uchun darsdan tashqari vaqtda kompyuter xonasidan foydalanishga ruxsat berishingizni so'rayman.*
6. **6-Qadam (Sana va imzo):** Enter bosing, chap burchakka bugungi sanani, `Tab` tugmasi orqali o'ng chetga imzo va familiyangizni joylashtiring. Hujjatni `Ariza_Namunasi.docx` nomi bilan saqlang (`Ctrl + S`).

{% hint style="warning" %}
**Qat'iy xatolik:**
Hech qachon xatboshini (abzas boshini) bo'shliq (Probel) tugmasini 5-10 marta bosib surishga urinmang! Hujjat boshqa kompyuterda ochilganda yoki boshqa shrift tanlanganda bu probellar butun matn qatorlarini buzib, chalkashtirib yuboradi. Faqat chizg'ich yoki `Tab` tugmasidan foydalaning!
{% endhint %}

## 4. 🛠 Real Ish Vaziyati va Muammolarni Hal Qilish (Case-Study)

### Muammo:
Xodim 20 sahifalik hisobot tayyorladi. Ammo matn juda xunuk: qatorlarning oxiri arra tishlaridek uzuq-yuluq, ba'zi so'zlar orasida 3-4 tadan ortiqcha bo'shliqlar bor, abzaslar esa har xil masofadan boshlangan. Rahbariyat hujjatni qabul qilmadi va uni 10 daqiqa ichida tartibga keltirishni buyurdi.

### Muammoning Kelib Chiqish Sababi:
1) Matn ikki tomonga tekislanmagan (Justify qilinmagan);
2) Matn terayotganda ortiqcha ko'p probellar bosilgan;
3) Birinchi satr xatboshisi chizg'ich orqali sozlanmagan.

### Bosqichma-bosqich Yechim:
1. `Ctrl + A` bosing (butun hujjat belgilanadi) va `Ctrl + J` bosing (hujjatning o'ng va chap qirralari chizg'ichdek tekis bo'ladi).
2. Ortiqcha probellarni bir soniyada yo'qotish: `Ctrl + H` (Almashtirish / Replace) darchasini oching.
   * "Find what" qatoriga ikkita probel `  ` qo'ying;
   * "Replace with" qatoriga bitta probel ` ` qo'ying;
   * **Replace All** tugmasini bosing (to barcha 0 ta almashtirish qolguncha takrorlang).
3. Gorizontal chizg'ichni yoqing (**View -> Ruler**) va yuqori uchburchakni (First Line Indent) **1.25 sm** ga suring.
4. 20 betlik matn 2 daqiqada ideal rasmiy holatga keladi!
